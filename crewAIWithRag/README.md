# 学生信息管理与汇总

这个子项目现在定位为本地学生信息台账系统。它不依赖大模型即可使用，不消耗 API token，数据保存到本地 SQLite 数据库 `data/students.db`。

## 当前功能

- 学生信息新增、编辑、删除、搜索
- Excel/CSV 导入，按唯一学号合并
- 空值不覆盖原值
- 同学号但姓名不同进入人工核对，不自动修改
- 新导入文件里出现未知列时，先进入导入核对；确认后可新增为动态字段
- 动态字段默认文本，可在网页端改成下拉列表并设置选项
- 奖惩记录新增、删除和统计
- 首页统计看板：总人数、性别、缺失字段、奖惩数量、待核对变更、活动总分，并附带动态图表
- 数据详情页：学生列表、导入、核对、编辑、奖惩、日常活动集中维护
- 日常活动/志愿服务：记录时间、任务名称、任务量、时长、分数和计算规则
- 高级筛选：班级、导师、寝室位置、性别、政治面貌、三方、去向类型、缺联系电话、有奖惩记录
- 批量编辑选中学生
- Excel 导出弹窗，默认导出学生信息，可选择同时导出奖惩记录、日常活动

## 字段

基础字段：

- 姓名
- 班级
- 学号
- 联系电话
- 寝室位置
- 寝室号
- 导师姓名
- 性别
- 政治面貌
- 是否签署三方
- 去向类型
- 单位名称
- 岗位
- 城市
- 是否升学
- 去向备注

去向类型下拉包含：未知、国企、私企、事业单位、公务员、升学、科研院所、高校、参军、自主创业、自由职业、待就业、其他。

## 启动

```powershell
cd .\crewAIWithRag
python main.py
```

启动后浏览器打开：

```text
http://127.0.0.1:8013/
```

注意：终端里显示的 `0.0.0.0:8013` 是服务绑定地址，浏览器请使用 `127.0.0.1:8013`。

## 修改端口

```powershell
$env:STUDENT_INFO_PORT="8020"
python main.py
```

## 导入表格规则

导入 Excel/CSV 至少需要包含：

- 姓名或学生姓名
- 学号

常见表头会自动识别，例如：

| 系统字段 | 可识别表头 |
| --- | --- |
| 姓名 | 姓名、学生姓名、名字 |
| 班级 | 班级、所在班级、行政班 |
| 学号 | 学号、学生学号 |
| 联系电话 | 联系电话、电话、移动电话、手机号、手机号码、联系方式 |
| 寝室位置 | 寝室位置、宿舍位置、所在寝室楼、所在宿舍楼、寝室楼、宿舍楼、公寓 |
| 寝室号 | 寝室号、宿舍号、房间号、寝室、宿舍 |
| 导师姓名 | 导师姓名、导师、指导老师、辅导员、班主任 |
| 政治面貌 | 政治面貌、政治身份 |
| 是否签署三方 | 是否签署三方、三方、三方协议、签署三方 |
| 去向类型 | 去向类型、毕业去向、就业去向、去向 |

## 导入后的人工核对

如果新文件中的字段值与已有数据不同，系统不会直接覆盖，而是在“导入核对”里显示原值和新值。你可以选择：

- 使用新值
- 使用手动值
- 保留原值

如果新文件中出现 `QQ号` 这类原系统没有的列，也会先进入“导入核对”。确认后，它会出现在“字段设置”里，可以继续配置为文本或下拉列表。

## 首页和数据详情页

打开网页后默认进入首页。首页只展示欢迎语、关键数字和可视化图表。

点击“进入数据详情页”后，才进入学生数据维护界面。这里可以：

- 搜索和筛选学生
- 导入 Excel/CSV
- 处理导入核对
- 编辑学生详情
- 添加奖惩记录
- 添加日常活动/志愿服务
- 打开导出弹窗并选择导出类别

首页中的“未知/未填 226”表示当前 226 个学生的性别字段还没有填写，不是导入失败。

## 日常活动积分

日常活动支持以下计算规则：

- 任务量 * 时长
- 只按任务量
- 只按时长
- 固定分数

在网页中修改任务量、时长或计算规则时，实时分数会同步更新。保存后，学生的志愿服务总分会立即刷新。
